# YouTube Clone - Full-Stack Capstone Project

## Project Overview
Developed a full-stack video streaming web application replicating core Youtube functionalities, including highly dynamic navigation, video player, comments, like, and channel creation, and so on.
This project delivers an end-to-end video streaming, dynamicness, and interactivity. It bridges client-side media consumption with a robust and secure backend service capable of handling media file, user authentication, and dyamic social interations. 

## Features
- Dynamic and Responsive UI:
  Developed highly responsive and dynamic UI which is compatible for 30+ devices.
- Proper Interativity
- CRUD Operations
- Secure RESTAPIs design
- User Authentication and Authorization (via JWT)
  Authentication & Authorization: Secure registration, login mechanisms, and protected API routing using JWT.
- Interactive Player
  Custom video player interface supporting standard playback controls and automatic view count increments.
- Social Engagement
  Functional comment threads, like/dislike counters.
- Search & Filter: User can filterout many videos based on its categories via   clicking on multiple filter button and perform search by video title.
- Increasing Password Security through Bcrypt
- Enabling CORS to avoid access issues
- Proper alert on every updates
- Input Validation
- Error Handling

## Install Dependencies and Launch the Development Environments
### 1. For Backend
```bash
# Install nodemodules
cd Youtube_Clone_App && npm install 

#Run backend server
cd Youtube_Clone_App && cd server && > nodemon server.js 

```
### 2. For Frontend  
```bash
# Install nodemodules
cd Youtube_Clone_App && cd client && npm install

#Run fronted application
cd Youtube_Clone_App && cd client && > npm run dev

```
